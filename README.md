# OnlyGuests

Справочник кафе, кофеен и ресторанов Алматы: 100 заведений с рейтингом 2ГИС, годом открытия, меню и тремя фото.

Сайт статический (HTML + CSS + JS), сборка не нужна.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Для публикации подойдёт любой статический хостинг: GitHub Pages, Vercel, Netlify.

## Что есть на сайте

- поиск по названию, кухне, блюду или улице;
- фильтры по типу заведения (ресторан, кофейня, кафе, бар, фастфуд, кондитерская) и по кухне;
- сортировка по рейтингу, числу оценок, году открытия и названию;
- карточка заведения: галерея из трёх фото, рейтинг 2ГИС с числом оценок, год открытия, средний чек, адрес, меню и ссылка на 2ГИС;
- ссылка на конкретное заведение, например `/#turandot`;
- светлая и тёмная тема, вёрстка под телефон.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | стили |
| `js/app.js` | поиск, фильтры, карточки, модальное окно |
| `js/data.js` | данные о 100 заведениях (`window.CAFES`) |
| `tools/build_data.py` | генератор `js/data.js`: исходный список заведений, шаблоны меню и подбор фото |

## Откуда данные и насколько им можно доверять

- **Рейтинг и число оценок.** Взяты из карточек 2ГИС через веб-поиск в октябре 2026 года. У сетей указан конкретный филиал (его адрес в карточке). Рейтинги меняются, поэтому в каждой карточке есть кнопка «Открыть в 2ГИС». У трёх заведений (Manga, Мармарис, Огонёк) рейтинг приблизительный и помечен «≈».
- **Год открытия.** Указан у 26 заведений, только если год подтверждён источником (forbes.kz, kapital.kz, kursiv.media, sxodim.com, пресс-релизы). Пометка «≈» значит, что год приблизительный, например «работает не позднее». У сетей иногда указан год основания сети, это написано в пояснении. У остальных стоит «нет данных».
- **Меню.** Популярные позиции для кухни заведения с ориентировочными ценами, рассчитанными от среднего чека. Фирменные блюда отмечены. Это не выгрузка официального меню: актуальное меню смотрите в 2ГИС.
- **Фото.** Иллюстративные снимки с Unsplash, подобранные по типу кухни. Реальных фото заведений здесь нет. Их можно заменить в поле `photos`.

## Как обновить или добавить заведение

1. Откройте `tools/build_data.py` и измените или добавьте строку `add(...)` (рейтинг, число оценок, адрес, ссылку на 2ГИС, год).
2. Пересоберите данные:

   ```bash
   python3 tools/build_data.py js/data.js
   ```

Можно править и сам `js/data.js`, но тогда следующая сборка из `build_data.py` перезапишет эти правки.
