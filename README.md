# OnlyGuests

Справочник кафе, ресторанов, баров, бистро, донерных, бургерных и магазинов (Magnum, Small, Toimart, CU) Алматы. У каждого места есть рейтинг 2ГИС, год открытия, средний чек, часы работы, район, точка на карте, меню (у магазинов — популярные товары) и три фото. Рейтинги регулярно перепроверяют ИИ-агенты на бесплатных моделях.

Онлайн: https://onlyguests.vercel.app (пересобирается после каждого пуша в `main`) и [артефакт OnlyGuests](https://claude.ai/artifact/C64RgBkRn5tLP3ogeBge8B).

## Что умеет сайт

- **ИИ-помощник «Куда пойти?»** понимает запросы на русском, казахском и английском, например «грузинская кухня с детской комнатой до 8000 ₸ рядом со мной». Сначала сайт сам разбирает запрос и подбирает места. Если на Vercel задан ключ бесплатной модели, ИИ выбирает три лучших варианта и объясняет выбор.
- **Карта** (Leaflet + OpenStreetMap), кнопка «Рядом со мной» и сортировка по расстоянию. Leaflet и подложка лежат в репозитории (`vendor/`, `img/map-almaty.jpg`), поэтому карта работает даже без внешних серверов, в том числе в артефакте. Чёткие плитки OpenStreetMap подгружаются поверх, если доступны.
- **«Открыто сейчас»** по часам работы и времени Алматы, а в карточке есть расписание по дням.
- **Фильтры:**
  - поиск;
  - тип места;
  - кухня;
  - район;
  - ползунок среднего чека;
  - удобства: детская комната, намазхана, халал, веранда, живая музыка, круглосуточно, с питомцами.
- **Подборки:** свидание, завтраки, с видом на горы, поработать с ноутбуком, бизнес-ланч до 3000 ₸, куда с детьми, ночью, недорого.
- **Избранное ♥ и «Хочу сходить» 🔖** без регистрации, хранятся в браузере.
- **Сравнение** 2–4 мест в одной таблице.
- **Мне повезёт 🎲:** случайное место с учётом фильтров, лучшие выпадают чаще.
- **Рейтинг недели:** кто вырос и кто упал по данным агентов.
- **График рейтинга** в карточке места.
- **Выжимка отзывов** («хвалят / ругают») от агента-аналитика.
- **«На радаре»:** новые места, которые нашёл агент-разведчик.
- **Три языка:** RU, KZ, EN. Тексты справочника переведены, новые строки переводит агент.
- **Партнёрство за 10 000 ₸:** значок «Партнёр», место выше в списке с пометкой «Реклама», приоритет в помощнике и боте. Партнёры задаются в `PARTNERS` в `tools/build_data.py`.
- **Кабинет владельца:** форма заявки на обновление карточки или партнёрство уходит в WhatsApp или на почту.
- **Связь с разработчиком:** +7 700 683 02 47 (звонок и WhatsApp), ItsTeamSwift@proton.me.
- **Telegram-бот:** поиск словами, кнопки-меню, геопозиция, карточка места с фото, листание «Ещё», инлайн-режим (`@бот запрос`) и кнопка «Сайт» в меню.
- **SEO:**
  - у каждого места своя страница `place/<id>` с разметкой schema.org;
  - есть `sitemap.xml` и `robots.txt`;
  - в подвале главной есть список ссылок на все места.

## ИИ-агенты

Все агенты работают на бесплатных моделях и запускаются в GitHub Actions (`.github/workflows/agents.yml`). Каждый коммитит результат в `main`, после чего Vercel пересобирает сайт.

| Агент | Когда | Что делает | Файл |
|---|---|---|---|
| «Искатель» и «Проверяющий» | каждые 6 часов | Независимо сверяют рейтинг 2ГИС, число оценок, часы работы и не закрылось ли место. Значение принимается, только если агенты сошлись (разница ≤ 0.1). Скачки больше 0.5 и падение числа оценок отбрасываются. Ведётся история для графика и рейтинга недели. | `js/live.js` |
| «Аналитик» | каждый день | Читает свежие отзывы, пишет «хвалят / ругают» и метки для подборок. | `js/insights.js` |
| «Переводчик» | каждый день | Переводит новые тексты на казахский и английский. | `js/i18n-data.js` |
| «Разведчик» | по понедельникам | Ищет новые места Алматы. Второй агент проверяет их по 2ГИС, подтверждённые находки попадают в блок «На радаре» и в issue репозитория. | `js/scout.js` |

Код агентов лежит в `tools/` (`agent_update.py`, `agent_reviews.py`, `agent_translate.py`, `agent_scout.py`). Общий модуль моделей — `tools/ai.py`.

### Как включить (всё бесплатно)

Добавьте ключи в репозиторий: Settings → Secrets and variables → Actions → New repository secret. Достаточно одного варианта:

1. **OpenRouter + поиск.** Это бесплатные модели OpenRouter (DeepSeek, Llama, Qwen, Gemma с суффиксом `:free`).
   - `OPENROUTER_API_KEY` — ключ с https://openrouter.ai/keys.
   - `TAVILY_API_KEY` — https://tavily.com, бесплатно 1000 запросов в месяц. Вместо него можно `BRAVE_API_KEY` с https://brave.com/search/api/.
   - Конкретную модель можно задать переменной `OPENROUTER_MODEL` (вкладка Variables). Иначе берётся лучшая бесплатная из списка OpenRouter.
2. **Gemini.** `GEMINI_API_KEY` с https://aistudio.google.com/apikey. Модель сама ищет в Google, отдельный поиск не нужен.
3. **Без ключей.** `tools/agent_translate.py` («Переводчик») работает на бесплатной модели Pollinations и без регистрации. Рейтинговым агентам нужны свежие данные из интернета, поэтому им нужен ключ поиска или Gemini.
4. **Ollama.** Переменная `USE_OLLAMA = true` поднимает Ollama прямо в GitHub Actions. Модель задаётся в `OLLAMA_MODEL`, по умолчанию `qwen2.5:3b`. Без поиска Ollama подходит для «Переводчика», а с `TAVILY_API_KEY` — для всех агентов.

Лучше всего работают два источника сразу, например Gemini и OpenRouter с Tavily: тогда «Искатель» и «Проверяющий» идут разными маршрутами. `DGIS_API_KEY` (официальный API 2ГИС, платный) необязателен.

Первый запуск можно сделать вручную: Actions → AI agents → Run workflow.

Локально:

```bash
GEMINI_API_KEY=... python3 tools/agent_update.py --limit 5     # рейтинги
OPENROUTER_API_KEY=... TAVILY_API_KEY=... python3 tools/agent_reviews.py --limit 3
OLLAMA_HOST=http://localhost:11434 python3 tools/agent_translate.py
python3 tools/agent_update.py --mock --dry-run                  # проверка логики без сети
```

## ИИ-помощник и Telegram-бот (функции Vercel)

`api/ask.js` и `api/telegram.js` работают **сразу, без ключей**: выбор мест делает бесплатная модель Pollinations (без регистрации). Порядок источников: `GEMINI_API_KEY` (если задан) → Pollinations → бесплатные модели OpenRouter (`OPENROUTER_API_KEY`). Источники подключаются по очереди и только если предыдущий не ответил, а одинаковые запросы кэшируются на час. Бесплатный ключ OpenRouter без пополнения даёт всего 50 запросов в сутки на все бесплатные модели; пополнение на $10 поднимает лимит до 1000 в сутки (деньги при этом не списываются за бесплатные модели). Если все модели недоступны, помощник сам подбирает места по правилам. Переменные задаются в Vercel: Project → Settings → Environment Variables.

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather (без него бот не отвечает) |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная строка из букв и цифр |
| `OPENROUTER_API_KEY` или `GEMINI_API_KEY` | по желанию, более сильные модели |
| `NO_POLLINATIONS=1` | выключить запасную модель без ключа |

**Как включить бота:**

1. В Telegram откройте @BotFather → `/newbot` → скопируйте токен.
2. В Vercel добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`, затем нажмите Redeploy.
3. Один раз откройте `https://onlyguests.vercel.app/api/telegram?setup=<TELEGRAM_WEBHOOK_SECRET>`: подключится вебхук, команды на трёх языках, кнопка «Сайт» в меню и описание бота. Проверить состояние можно по `…/api/telegram?info=<секрет>`.
4. Чтобы работал инлайн-режим, в @BotFather выполните `/setinline` и укажите подсказку, например «халал рядом».

## Запуск

Сайт статический, сборка не нужна:

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## Откуда данные

- **Рейтинг и число оценок** взяты из карточек 2ГИС (октябрь 2026), дальше их обновляют агенты. Если 2ГИС показывал противоречивые цифры, рейтинг помечен «≈».
- **Год открытия** указан, только если подтверждён источником. У сетей это год основания сети, о чём есть пояснение.
- **Средний чек** взят из 2ГИС. Если его нет, чек оценён по типу места и помечен «≈».
- **Часы работы** взяты из карточек 2ГИС, OpenStreetMap и от агентов. **Координаты и районы** — из OpenStreetMap/Nominatim.
- **Меню и товары** — популярные позиции с ориентировочными ценами, не официальная выгрузка.
- **Фото** иллюстративные (Unsplash).

## Как добавить место

1. Добавьте строку `add(...)` в `tools/build_data.py`.
2. Выполните:

   ```bash
   python3 tools/build_data.py js/data.js   # данные
   python3 tools/geocode.py                 # координаты и район новых мест
   python3 tools/build_data.py js/data.js   # подмешать координаты
   python3 tools/agent_translate.py         # переводы (нужна модель или ручной перевод в tools/i18n_seed.json)
   python3 tools/build_pages.py             # SEO-страницы
   ```
