# OnlyGuests

Справочник кафе, кофеен и ресторанов Алматы: 200 заведений с рейтингом 2ГИС, годом открытия, средним чеком, удобствами, меню и тремя фото.

Сайт статический (HTML + CSS + JS), сборка не нужна.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Онлайн-версии: https://onlyguests.vercel.app (пересобирается после каждого пуша в `main`) и [артефакт OnlyGuests](https://claude.ai/artifact/C64RgBkRn5tLP3ogeBge8B).

## Что есть на сайте

- поиск по названию, кухне, блюду или улице;
- ползунок «средний чек до …» и фильтры по удобствам: детская комната, намазхана, халал, летняя веранда, живая музыка, круглосуточно, можно с питомцами;
- фильтры по типу заведения (ресторан, кофейня, кафе, бар, фастфуд, кондитерская) и по кухне;
- сортировка по рейтингу, числу оценок, году открытия и названию;
- карточка заведения: галерея из трёх фото, рейтинг 2ГИС с числом оценок, год открытия, средний чек, адрес, меню и ссылка на 2ГИС;
- ссылка на конкретное заведение, например `/#turandot`;
- рейтинги перепроверяют ИИ-агенты: если рейтинг изменился, на карточке видно, каким он был;
- блок «Написать разработчику» (телефон, WhatsApp, почта) и кнопка «Сообщить о неточности» в каждой карточке;
- светлая и тёмная тема, вёрстка под телефон.

## ИИ-агенты

Каждые 6 часов GitHub Actions (`.github/workflows/agents.yml`) запускает `tools/agent_update.py`:

1. Если задан секрет `DGIS_API_KEY`, скрипт берёт рейтинг и число оценок из официального API 2ГИС.
2. Иначе работают два агента на бесплатной модели Gemini (`gemini-2.5-flash`) с поиском Google. «Искатель» находит рейтинг, «Проверяющий» перепроверяет его отдельным запросом. Значение принимается, только если они сошлись (разница не больше 0.1).
3. Ответы с резким скачком рейтинга (больше 0.5) или с заметным падением числа оценок отбрасываются.
4. Свежие значения пишутся в `js/live.js`, робот коммитит его в `main`, и Vercel пересобирает сайт.

За один запуск проверяется 40 заведений, сначала те, что дольше всего не проверялись. Все 200 обходятся примерно за сутки.

**Как включить:** получите бесплатный ключ на https://aistudio.google.com/apikey и добавьте его в репозиторий: Settings → Secrets and variables → Actions → New repository secret, имя `GEMINI_API_KEY`. Первый запуск можно сделать вручную: Actions → AI agents → Run workflow.

Локально: `GEMINI_API_KEY=... python3 tools/agent_update.py --limit 5`. Без сети можно проверить логику: `python3 tools/agent_update.py --mock --dry-run`.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | стили |
| `js/app.js` | поиск, фильтры, карточки, модальное окно, наложение свежих рейтингов |
| `js/live.js` | свежие рейтинги от ИИ-агентов (`window.LIVE`), обновляется автоматически |
| `tools/agent_update.py` | ИИ-агенты, которые перепроверяют рейтинги |
| `.github/workflows/agents.yml` | расписание агентов (каждые 6 часов) |
| `js/data.js` | данные о 200 заведениях (базовые) (`window.CAFES`) |
| `img/` | фото (68 снимков с Unsplash, хранятся в репозитории) |
| `tools/build_data.py` | генератор `js/data.js`: исходный список заведений, шаблоны меню и подбор фото |

## Откуда данные и насколько им можно доверять

- **Рейтинг и число оценок.** Взяты из карточек 2ГИС через веб-поиск в октябре 2026 года. У сетей указан конкретный филиал (его адрес в карточке). Рейтинги меняются, поэтому в каждой карточке есть кнопка «Открыть в 2ГИС». У нескольких заведений (например, Мармарис, Огонёк) рейтинг приблизительный и помечен «≈».
- **Год открытия.** Указан у 26 заведений, только если год подтверждён источником (forbes.kz, kapital.kz, kursiv.media, sxodim.com, пресс-релизы). Пометка «≈» значит, что год приблизительный, например «работает не позднее». У сетей иногда указан год основания сети, это написано в пояснении. У остальных стоит «нет данных».
- **Средний чек.** Из 2ГИС, если указан. Иначе — оценка по типу заведения, помечена «≈».
- **Удобства.** Отмечены по карточкам и тематическим подборкам 2ГИС (детские комнаты, намазханы, халал и т. д.). Список может быть неполным.
- **Меню.** Популярные позиции для кухни заведения с ориентировочными ценами, рассчитанными от среднего чека. Фирменные блюда отмечены. Это не выгрузка официального меню: актуальное меню смотрите в 2ГИС.
- **Фото.** Иллюстративные снимки с Unsplash, подобранные по типу кухни и сохранённые в `img/`. Реальных фото заведений здесь нет. Их можно заменить в поле `photos`.

## Как обновить или добавить заведение

1. Откройте `tools/build_data.py` и измените или добавьте строку `add(...)` (рейтинг, число оценок, адрес, ссылку на 2ГИС, год).
2. Пересоберите данные:

   ```bash
   python3 tools/build_data.py js/data.js
   ```

Можно править и сам `js/data.js`, но тогда следующая сборка из `build_data.py` перезапишет эти правки.
